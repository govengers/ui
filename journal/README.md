# journal

- `YYYY-MM.md`: one line per workbook run or change a session made in this repository. Append
  only; grep, never load whole.
- `runs/`: one report per workbook run, written by the mandatory learn stage; compiled by the
  `groom` workbook (template in `runs/README.md`).
- `deferred.md`: findings seen once, waiting for a second occurrence (written by `groom`).
