# ui-page

Entry point for the `build-page` workbook (ICM). Do not improvise the procedure here.

1. `docs/ui/workbooks/build-page/CONTEXT.md` in the project (copied by `ui-start`); without it,
   `<source>/workbooks/build-page/CONTEXT.md`.
2. Read the project's `DESIGN.md` and `src/ui/INDEX.md` first, as stage `01-recipe` says; then run
   the stages in order, loading only what each names (the recipe card, the blocks' cards, the
   laws the recipe names).
3. The run is not done before `06-learn` has written its report.
