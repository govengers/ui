# ui-maintain

Entry point for the `maintain-collection` workbook (ICM). Runs only inside the govengers/ui
checkout. Do not improvise the procedure here.

1. Read `CLAUDE.md` (rules), then `workbooks/maintain-collection/CONTEXT.md`.
2. Run the stages from `01-place`, loading only what each stage names (the closest existing
   piece is the pattern to copy).
3. The run is not done before `05-learn` has written its report in `journal/runs/`.
