# AGENTS.md

The routing table and rules for every coding agent live in [CLAUDE.md](CLAUDE.md) (the L0 of the
ICM structure, `workbooks/README.md`). Read it, then the workbook the task shape maps to, then
only what that workbook's current stage names.

Quick paths:

- Use a piece in a project: `workbooks/copy-piece/` (skill `ui-copy`).
- Build a page in a project: `workbooks/build-page/` (skill `ui-page`).
- Set a project up: `workbooks/start-project/` (skill `ui-start`); its direction step is
  `workbooks/design-direction/`.
- Review UI work: `workbooks/review-ui/` (skill `ui-review`).
- Change this collection: `workbooks/maintain-collection/` (skill `ui-maintain`).
- Find anything: [INDEX.md](INDEX.md), then the card next to the code.
