# Stage 01: brief

## Input
What the human says about the product; the product's own documents if any (`PRODUCT.md`,
README, a pitch).

## Process
1. Ask, in one message, only what the documents do not answer: what the product is and for whom
   (one sentence), how using it should feel (one sentence), three adjectives, what the user must
   never feel (lost, rushed, unsure whether it saved), the devices and the light the product is
   used in (desk, shop floor, phone outdoors), an existing brand (colours, fonts, logo).
2. Write the answers down verbatim; do not interpret yet.

## Output
```
product: <sentence>
tone: <sentence>
adjectives: <a, b, c>
never: <...>
context: <devices, light, environment>
brand: <none | colours, fonts, logo file>
```

## Completion
Proceed to `02-direction`.
