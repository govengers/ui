# Stage 04: contract

## Input
The direction sentences, the preset block, `templates/project/DESIGN.md`.

## Process
1. Fill the Direction section with the brief's four lines and the eight sentences; the Preset
   section with the preset, themes, density, overrides and fonts.
2. Add the laws cited to a short "Why" list under Direction so a later reviewer sees the
   argument, not only the outcome.
3. Everything else in `DESIGN.md` stays as `start-project` wrote or will write it.

## Output
```
DESIGN.md: Direction and Preset sections written
```

## Completion
Hand back to `start-project` stage 03 (or, in a re-direction, run `review-ui` on the existing
pages against the new contract). Then proceed to `05-learn`.
